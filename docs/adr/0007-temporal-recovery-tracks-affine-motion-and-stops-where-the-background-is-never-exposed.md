# 0007 — Temporal Recovery は affine で動きを追い、背景が露出しない所では戻さない

## 決定

- フレーム間の動きのモデルに affine（平行移動 + 回転 + 拡大縮小 + せん断）を足し、**既定にする**
  （`vrestore restore --motion affine|translation`、GUI は M で切り替え）
- affine の推定（`src/motion.zig`）:
  - 画面を 6 x 4 のブロックに分け（ROI とその周りの帯に、探す範囲を含めて重なるブロックは使わない）、
    隣り合うフレームで各ブロックの動きを ZNCC で探す。中心は既存の低周波の位相相関の平行移動、範囲は ±8 px。
    放物線で小数点以下まで出す
  - 模様の無いブロック（輝度の標準偏差 < 4）、ZNCC < 0.9、探す範囲の端で最大のブロックは使わない
  - ブロックの動きに affine を当てはめる。3 点の組をすべて試し（乱数を使わない RANSAC）、残差 1 px 未満の
    ブロックが 6 個以上かつ 6 割以上なら採用。足りなければ「推定できなかった」で鎖を切る
- 復元は、累積した affine でフレーム t の画素がフレーム s のどこに写るかを求め、双線形補間で借りる。
  使う 4 画素のどれかが ROI の中か画面の外なら借りない。写し先が整数（平行移動）ならその画素をそのまま使う
- ROI の周りの帯による整合性チェック（ADR 0005）、由来 `temporal_real`（ADR 0006）、coverage の定義は変えない。
  帯のチェックも affine で写した位置で行う
- ROI 周辺の block motion / optical flow は **入れない**（下の理由）

## 理由

- 間違った画素を貼らないことを coverage より優先する（オーナーの方針）。affine は、測ったすべての素材で
  外れた画素を減らした:
  - 合成 216 ケース全体: 戻した画素のうち外れた画素 0.062% → 0.010%
  - 手持ちの実写 72 ケース: 1.76% → 0.24%（再エンコードだけでも最大 1.1% 外れる）
- 回転・ズームを含む合成の動きで、戻せる範囲と正確さが上がる（中央の ROI、12 ケースの平均）:
  回転 0.2 度 + パン 5,2 で SSIM 0.464 → 0.813（上限 0.927）、ズーム 0.3% + パン 5,2 で 0.447 → 0.796（上限 0.931）。
  平行移動だけの合成では同等（パン 7,3・中央 0.901 → 0.908）
- block motion / optical flow を入れない理由: 手持ちの実写で戻らないのは、動きのモデルの精度ではなく、
  **ウォーターマークの下の背景が窓の中で露出していない** ため。affine で追った ROI の中心の動きは、前後 15 フレームで
  中央値 3.3 px / 8.7 px（2 区間）、ROI は 183 x 43。窓を前後 60 フレームに広げても、ウォーターマークの外接矩形の
  うち戻せたのは 1.5% 以下（6 ケース）。局所的な動きを細かく追っても、露出していない背景は戻せない
- 平行移動のモデルが手持ちの実写で「戻した」画素の多くは、±1 px の推定の揺れを累積して背景が動いたと
  見なしたもので、帯のチェック無しでは 29.8% が外れていた。affine は小数点以下まで動きを追うので、
  動いていない背景を動いたと見なさない（帯のチェック無しでも戻す割合が 15.4% → 0.5%）

## 採らなかったもの

- **平行移動を既定のまま残す**: 外れた画素が多い（上の数値）。手持ちの実写で「戻した」と言える画素が
  増えるのは、その多くが揺れの累積による見かけの露出だから
- **ROI 周辺の block motion / optical flow**: 上の通り、この素材では露出していない背景がボトルネック。
  被写体ごとの動き（背景の手前を人が横切る等）を扱う必要が出たら見直す
- **窓を広げる（前後 60 フレーム）**: 手持ちの実写 6 ケースで戻る割合は 1.5% 以下のまま、処理は 4 倍

## 帰結

- 処理が遅くなる: 640x360・60 フレームで 0.7 秒 → 1.9 秒（ReleaseFast、合成 3 ケースで観測）
- 角の ROI では、平行移動より coverage が下がることがある（パン 7,3: 0.426 → 0.367、パン 3,1: 0.294 → 0.205）。
  代わりにそこで外れた画素が 0.10% → 0.01%、0.28% → 0.00%
- 画面の中心を軸にした回転・ズームで ROI が中心付近にあると、背景がほとんど動かないので戻らない（どちらのモデルでも）
- 平行移動は `--motion translation` で残す。平行移動の出力は affine への一般化の前後で同じ
  （合成 120 ケースの評価値 2,880 個が一致、SPEC §4）
