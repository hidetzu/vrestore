# 0011 — ウォーターマークのマスクは、どのフレームでも同じ縁も隠し、ROI より少し広く見る

ADR 0010 のマスクを 3 点変える。

## 決定

- 変わりにくい画素（ADR 0010）に加え、勾配（明るさの中心差分）の時間方向の中央値の大きさが、
  背景（変わりにくくない画素）の中央値の 5 倍（下限 8）を超える画素を縁として隠す側に足す（`src/wmask.zig` の `edges`）
- 全体を広げる幅を 1 px → 2 px にする
- マスクを推定して埋める範囲は、ROI の周り 8 px まで広げる（`restore_cmd.maskArea`）。Temporal の範囲は ROI のまま
- マスクを使わず ROI 全体に戻す判定（隠す割合 2%〜95%）は、縁を足す前・広げる前の「変わりにくい画素」の割合で行う
- 既定は変えない（`--mask none`）

## 理由

- 半透明のウォーターマークは背景と一緒に色が変わるので、変わりにくさだけでは背景と見分けにくい。
  手持ちの固定カメラの素材に焼き込んだ不透明度 50% の URL で、本物のウォーターマークの画素の 64% しか隠せず、
  外接矩形の SSIM が焼き込んだままより低かった（0.155）。ウォーターマークの縁はどのフレームでも同じ向きの勾配を持ち、
  背景の縁は動くと時間で打ち消し合う（Dekel et al. 2017 と同じ手がかり）。縁を足すと、実写 96 ケースで
  再現率の最小が 0.644 → 0.9987 になった（SPEC §4）
- 縁のしきい値を背景基準にするのは、ROI 全体の中央値を基準にすると、ROI のうちウォーターマークが占める割合
  （= 指定した範囲の広さ）でしきい値が大きく動くから（合成の「毎フレーム別の模様」で、範囲を 8 px 広げただけで
  しきい値が 151.7 → 8.1 になり、縁が 0 → 5845 画素になった）。下限 8 は、背景が平らで中央値が 0 に近いときに
  圧縮の雑音を縁と取らないため
- 縁を広げないのは、中心差分が両隣を見るので、縁はウォーターマークの外側 1 px まで既に付いているから
  （広げると、字の詰まった所で行の間まで埋まった）
- 2 px 広げるのは、手持ちの実写に元から焼かれていた縁取り付きの文字で、1 px だと文字の輪郭が点線のように残り、
  2 px でほぼ消えたから（目視、Python で同じ処理を再現して比べた）
- 範囲を ROI より広げるのは、手で選んだ範囲がウォーターマークより数 px 狭いと、はみ出した文字の端が残るから（同じ場面で観測）。
  ウォーターマークでない画素は入力のまま残るので、広げても推測は増えにくい。Temporal を広げないのは、広げると背景がより遠くまで
  動かないと見えないので戻せる画素が減るから（合成の遅いパンで同じ範囲の temporal_real が 430049 → 307902 画素、SSIM 0.856 → 0.801）
- 割合の判定を縁の前にするのは、縁を足した分で 95% を超えて ROI 全体に戻ると、変わりにくさで見分けられていたものまで
  捨てるから（A の 600 秒で 3 ケースがそうなり、SSIM が 0.15 下がった）

## 採らなかったもの

- **広げる幅を増やすだけ（縁なし）**: 3 px 広げても再現率の最小は 0.910（Python での試算、96 ケース）
- **縁を、変わりにくい画素の近く（2 / 4 px）に限る**: 隠す割合はほとんど減らず、再現率の最小が 0.91 / 0.95 に戻った（同じ試算）
- **マスクの外の画素は、Temporal で戻せても入力のままにする**: 合成のパンで SSIM 0.942 → 0.931、回転 0.920 → 0.908 に下がった
  （2 px 広げても、マスクのすぐ外に圧縮のにじみが残る）

## 追記（2026-09-29）: 見分けられないとき

見分けられないとき、前はマスクの範囲を捨てて ROI ぴったりを隠していた。手で選んだ ROI からはみ出した文字の端が残り、それを手がかりに
埋めて周りへにじんだ（手持ちの実写の先頭のフェード）。今は ROI の中をすべて隠し、周りの帯ではどのフレームでも同じ縁だけを 2 px 広げて隠す。
このときの縁の閾値は範囲全体の中央値から取る（背景が止まっていると、変わりにくくない画素はむしろ文字の方で、それを基準にすると閾値が高すぎた）。
⚠ 残る弱点: 背景が止まり、文字の方が大きく変わる（フェードなど）と、変わりやすさで「見分けられた」と判定され、背景の方を隠しうる（合成の単体テストで観測）。

## 帰結

- 隠す（推測で埋める）画素が増え、外接矩形の SSIM は縁を足す前より下がる（A 3 区間で平均 −0.04〜−0.06、固定カメラで +0.02、
  SPEC §4）。ROI 全体を埋めるよりは、4 素材とも平均で上
- 合成の「毎フレーム別の模様」は 0.758 → 0.689 に下がり、E2E の判定値を 0.72 → 0.67 にした（ROI 全体は 0.649）
- この評価のウォーターマークは縁のにじみが少なく、2 px の効果（点線が消える）は数値に出にくい
- 縁を求めるのに、マスクの推定の時間がかかる（ROI の画素ごとにフレーム数の中央値を 2 回）
