# 0011 — ウォーターマークのマスクは、どのフレームでも同じ縁も隠す

ADR 0010 のマスクに手がかりを 1 つ足す。

## 決定

- 変わりにくい画素（ADR 0010）に加え、勾配（明るさの中心差分）の時間方向の中央値の大きさが
  ROI の中央値の 5 倍（下限 2）を超える画素を縁とし、1 px 広げてから隠す側に足す（`src/wmask.zig` の `edges`）
- マスクを使わず ROI 全体に戻す判定（隠す割合 2%〜95%）は、縁を足す前・広げる前の「変わりにくい画素」の割合で行う
- 既定は変えない（`--mask none`）

## 理由

- 半透明のウォーターマークは背景と一緒に色が変わるので、変わりにくさだけでは背景と見分けにくい。
  手持ちの固定カメラの素材に焼き込んだ不透明度 50% の URL で、本物のウォーターマークの画素の 64% しか隠せず、
  外接矩形の SSIM が焼き込んだままより低かった（0.155）。ウォーターマークの縁はどのフレームでも同じ向きの勾配を持ち、
  背景の縁は動くと時間で打ち消し合う（Dekel et al. 2017 と同じ手がかり）
- 縁を足すと、実写の 96 ケースで再現率の最小が 0.644 → 0.9987 になり、入力のまま残して正解から外れた画素が
  7〜13 分の 1 になった（SPEC §4）。取りこぼしはウォーターマークが残る目に見える失敗で、ADR 0010 は迷ったら広く隠す
- 割合の判定を縁の前にするのは、縁を足した分で 95% を超えて ROI 全体に戻ると、変わりにくさで見分けられていたものまで
  捨てるから（A の 600 秒で 3 ケースがそうなり、SSIM が 0.15 下がった）

## 採らなかったもの

- **広げる幅を増やすだけ**: 3 px 広げても再現率の最小は 0.910（Python での試算、96 ケース）。半透明のものは縁の近くだけでなく
  字の中ほどまで取りこぼす
- **縁を、変わりにくい画素の近く（2 / 4 px）に限る**: 隠す割合はほとんど減らず（81% 前後）、再現率の最小が 0.91 / 0.95 に戻った
  （同じ試算）

## 帰結

- 隠す画素が増え、背景が動く A の 3 区間では外接矩形の SSIM が平均 0.03〜0.04 下がった。固定カメラでは平均 +0.04
- 背景のうち、動かない縁（固定カメラの部屋の輪郭など）も隠して推測で埋める。適合率は 0.30〜0.40 のまま
- 縁を求めるのに、マスクの推定の時間がかかる（ROI の画素ごとにフレーム数の中央値を 2 回）
