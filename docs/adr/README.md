# ADR — なぜそう決めたか

ここは**決定**を置く。設計や計画は置かない。
主張してよいことは [`../SPEC.md`](../SPEC.md)、進め方は [`../../CLAUDE.md`](../../CLAUDE.md)。

## 入れるもの

放っておくと議論し直しになる決定。特に:

- **採らなかった**もの、とその理由（ここが失われやすい）
- 実装が越えてはいけない境界

## 入れないもの

- 実装の説明（コードが言う）
- 計画（issue が言う）
- 件数・測定値（SPEC §4）
- 自明な判断

## 名前

```text
NNNN-決定を述べる文.md
```

ファイル名はトピックではなく決定を言う。
