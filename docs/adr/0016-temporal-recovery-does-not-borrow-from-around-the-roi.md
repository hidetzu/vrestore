# 0016 — Temporal Recovery は ROI の周りから借りず、移動の確かめもその外で行う

ADR 0005 / 0007（別のフレームの実画素を借りる）に、借りない範囲を足す。

## 決定

- 別のフレームから画素を借りるとき、次の範囲の画素は使わない（`temporal.Guard`）:
  - マスクを使えるとき（`--mask auto` で見分けられた）: マスクの範囲（ROI + 8 px）のうち、マスクで隠した画素
  - それ以外: ROI を 8 px 広げた範囲（`--temporal-guard` で変えられる）
- 借りる前の移動の確かめ（ROI の周りの帯、ADR 0007）は、その範囲のすぐ外の帯で行う
- 戻した画素の由来は今まで通り `temporal_real`

## 理由

- ROI の外にウォーターマークがはみ出していると、その縁を本物の背景として借りた。借りる画素は、背景の動きの分だけ ROI の縁から外に出た
  位置になるので、ちょうどはみ出しの帯に当たる（合成で、はみ出し 1 px の薄い縁で戻した画素の 30%、2 px で 63% が外れ）。
  濃い縁では帯の確かめが合わず、全フレームが拒否されて何も戻らなかった（合成のパン・遅いパン・回転で、ROI を 2 px 縮めると coverage 0）
- 手持ちの実写の全編で、戻した画素の 82% が ROI の縁から 4 px 以内にあった。手で選んだ ROI からは、ウォーターマークが左に 2 px、上に 1 px はみ出していた
- 合成で ROI をウォーターマークから 0 / 2 / 4 px 縮めたとき（パン・遅いパン・回転）、ROI + 8 px を守ると外れはすべて 0.02% 以下。ROI + 4 px では、はみ出し 4 px で外れ 0.6〜1.8% が残った
- 帯をはみ出しの外に置くと、確かめがウォーターマークの縁に邪魔されなくなり、coverage はむしろ上がった（パン、ROI = 外接矩形で 0.965 → 0.987）

## 採らなかったもの

- **ROI + 4 px**: はみ出しが 4 px だと外れが残る

## 実写での疑似チェック（ウォーターマークの無い場所に同じ大きさの矩形を置く、SPEC §4）

守る範囲は、はみ出しの無い場所では損しか生まない。手持ちの実写の 20 クリップで（左上 = 本物の ROI を左右反転した位置 / 中央）:
守る範囲なし coverage 0.0099 / 0.0172・外れ 8.0% / 1.5%、ROI + 3 px 0.0047 / 0.0036・9.4% / 2.6%、ROI + 8 px 0.0025 / 0.0007・11.3% / 7.0%。
広い範囲の外まで背景が動くフレームは、実写では画面全体の動きの近似が合いにくい（と考える、未検証）。
守る範囲なしでも、実写で戻した画素の外れは harmonic で埋めた場合と同程度だった。これを受けて、既定は ADR 0017 の auto にした

## 帰結

- 背景がゆっくり動く動画では、ROI の周り 8 px の外まで動かないと借りられないので、戻せる画素が減る
  （合成の遅いパン × crf 35 で coverage 0.680 → 0.475、回転 + パンで SSIM 0.739。合成 E2E の判定値を下げた）
- マスクを使うと、隠した画素だけを除くので、戻せる画素の減りは小さい（合成で coverage 0.62〜0.997）
