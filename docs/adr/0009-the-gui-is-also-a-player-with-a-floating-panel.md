# 0009 — GUI は動画プレイヤーとしても使え、操作は映像に重なるパネルで行う

## 決定

- `vrestore-gui` に再生 / 一時停止・シークバー・現在時刻とフレーム番号の表示を足す。QuickTime Player のように、
  映像の上に半透明の操作パネルを重ねる
- パネルはドラッグで動かせ、映像の表示領域の外へは出ない（窓の大きさが変わったら押し戻す）。一度も動かしていなければ
  映像の下寄り中央に置き続ける。H で隠す / 出す
- ROI の選択の邪魔にしない:
  - パネルの上で押した操作は ROI の選択にならない（再生ボタン / シークバー / パネルの移動のどれか）
  - ROI をドラッグで選んでいる間はパネルを描かない
  - 検出（Enter）・復元（R）・フレーム送り（← →）をすると再生を止める
- **キーの割り当てを変える: Space を再生 / 一時停止にし、処理前 / 処理後の切り替えを B に移す**
- 窓の下端にあったタイムライン（青い帯）は、操作パネルのシークバーと役割が重なるので取り除く。下端の帯は
  検出の得票率の棒だけにする
- 場面を共有するため、C で `<動画名> t=<秒> frame=<番号>` をクリップボードにコピーし、標準出力にも出す。
  `--frame <番号>` / `--at <秒>` で同じ場面を開ける
- パネルの文字（時刻・フレーム番号）は、数字と記号だけの 5 x 7 のビットマップフォント（`src/glyphs.zig`）で描く
- パネルの位置・当たり判定・入力の振り分け・再生の時計・表示と共有の文字列は、SDL に依存しない
  `src/player_state.zig` に置いてテストする。`gui.zig` はイベントを読んで描くだけ（ADR 0004 と同じ分け方）

## 理由

- 復元の結果は動画として見て判断することが多い。フレームを 1 枚ずつ送るだけでは、動いたときの見え方
  （ちらつき、埋めた部分の不自然さ）が分からない
- Space で再生するのは動画プレイヤーの慣習。処理前 / 処理後の切り替えは頻度が低いので、別のキーに移す
- ウォーターマークの改善を相談するとき、どの場面の話かを言葉で伝えるのは難しい。時刻は丸め方で食い違うので、
  フレーム番号も併せて出す
- 文字は数字と記号しか要らない。SDL_ttf やフォントファイルを足すほどではない（ADR 0004 の帰結で予告した見直し）

## 採らなかったもの

- **Space を処理前 / 処理後のまま残し、再生は別のキー**: 動画プレイヤーとして使うときに Space が効かないのは不便
- **パネルを映像の外（窓の下端）に固定する**: 窓の高さを取る。重ねて、動かせるようにした
- **SDL_ttf / SDL3 のデバッグ用フォント**: 依存が増える、Ubuntu 24.04 の apt に無い（ADR 0004）

## 帰結

- フレーム番号は「時刻 x 平均フレームレート」を丸めたもの。フレームレートが途中で変わる動画ではずれる
- 再生はフレームのデコードが間に合う範囲で実時間に合わせる。1 秒以上遅れたら読み進めずに seek する
  （その間のフレームは飛ばす）
- 音は出さない。フェードや音量の調整も無い
- マウスとキーの操作そのものは CI では回らない（ADR 0004 と同じ）。CI が見るのは、`player_state.zig` のテストと、
  `--frame` / `--play-frames` / `--share-and-exit` での場面の移動と共有の文字列まで
