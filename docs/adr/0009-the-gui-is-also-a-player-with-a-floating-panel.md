# 0009 — GUI は動画プレイヤーとしても使え、操作は映像に重なるパネルで行う

## 決定

- `vrestore-gui` に再生 / 一時停止・10 秒戻る / 進む・シークバー・現在時刻とフレーム番号の表示を足す。
  QuickTime Player のように、映像の上に角の丸い半透明の操作パネルを重ねる:
  1 段目にフレーム番号と「10 秒戻る / 再生・一時停止 / 10 秒進む」、2 段目に「経過時刻 ― シークバー ― 全体の長さ」
  （時刻は `00:13:32`）、3 段目に検出・復元の結果（あるときだけ）
- 窓のタイトルはファイル名だけにする（`A.mp4 — vrestore`）。検出・復元の数値はパネルの 3 段目に出す
- パネルはドラッグで動かせ、映像の表示領域の外へは出ない（窓の大きさが変わったら押し戻す）。一度も動かしていなければ
  映像の下寄り中央に置き続ける。H で隠す / 出す
- ROI の選択の邪魔にしない:
  - パネルの上で押した操作は ROI の選択にならない（再生ボタン / シークバー / パネルの移動のどれか）
  - ROI をドラッグで選んでいる間はパネルを描かない
  - 検出（Enter）・復元（R）・フレーム送り（← →）をすると再生を止める
- **キーの割り当てを変える: Space を再生 / 一時停止にし、処理前 / 処理後の切り替えを B に移す**
- 窓の下端にあった帯（青いタイムラインと、検出の得票率の赤 / 黄の棒）は取り除き、窓全体を映像に使う。
  タイムラインは操作パネルのシークバーと、得票率の棒はパネルの 3 段目の `confidence` / `RELIABLE` と役割が重なる
- 場面を共有するため、C で `<動画名> t=<秒> frame=<番号>` をクリップボードにコピーし、標準出力にも出す。
  `--frame <番号>` / `--at <秒>` で同じ場面を開ける
- パネルの文字は SDL2_ttf で、実行する環境のシステムフォントで描く（macOS は SF → Helvetica → Arial、Linux は DejaVu Sans
  → Liberation Sans → Noto Sans。`--font` / `VRESTORE_FONT` で差し替え）。見つからなければ、数字と記号だけの 5 x 7 の
  ビットマップフォント（`src/glyphs.zig`）で描く。時刻の数字は等幅に並べ、再生中に文字が揺れないようにする
- パネルの位置・当たり判定・入力の振り分け・再生の時計・表示と共有の文字列は、SDL に依存しない
  `src/player_state.zig` に置いてテストする。`gui.zig` はイベントを読んで描くだけ（ADR 0004 と同じ分け方）

## 理由

- 復元の結果は動画として見て判断することが多い。フレームを 1 枚ずつ送るだけでは、動いたときの見え方
  （ちらつき、埋めた部分の不自然さ）が分からない
- Space で再生するのは動画プレイヤーの慣習。処理前 / 処理後の切り替えは頻度が低いので、別のキーに移す
- ウォーターマークの改善を相談するとき、どの場面の話かを言葉で伝えるのは難しい。時刻は丸め方で食い違うので、
  フレーム番号も併せて出す
- 最初は数字と記号だけのビットマップフォントで描いたが、オーナーが見て、QuickTime Player のようななめらかな文字を
  求めた。SDL2_ttf は Homebrew（`sdl2_ttf`）と Ubuntu 24.04 の apt（`libsdl2-ttf-dev`）の両方にある。SF などは
  ライセンス上リポジトリに同梱できないので、環境にあるフォントを読む

## 採らなかったもの

- **Space を処理前 / 処理後のまま残し、再生は別のキー**: 動画プレイヤーとして使うときに Space が効かないのは不便
- **パネルを映像の外（窓の下端）に固定する**: 窓の高さを取る。重ねて、動かせるようにした
- **ビットマップフォントだけ**: 最初の版。見た目がオーナーの求める水準に届かなかった
- **フォントファイルを同梱する（オープンなライセンスのもの）**: 環境のシステムフォントで足りる。同梱すると 1 MiB 近い
  バイナリがリポジトリに入る
- **SDL3 のデバッグ用フォント**: Ubuntu 24.04 の apt に SDL3 が無い（ADR 0004）

## 帰結

- 実行時の依存に SDL2_ttf（と、それが使う FreeType など）が増える（`vrestore-gui` だけ）
- SDL2_ttf は pkg-config を使わずにリンクする。pkg-config を使うと SDL2 と SDL2_ttf の両方が SDL2 本体をリンクし、
  macOS（Homebrew の sdl2-compat）で起動時に「duplicate linked dylib」として止まった
- フォントが見つからない環境（CI の一部など）では数字と記号しか出ず、3 段目の情報の文字も欠ける
- フレーム番号は「時刻 x 平均フレームレート」を丸めたもの。フレームレートが途中で変わる動画ではずれる
- 再生はフレームのデコードが間に合う範囲で実時間に合わせる。1 秒以上遅れたら読み進めずに seek する
  （その間のフレームは飛ばす）
- 音は出さない。フェードや音量の調整も無い
- マウスとキーの操作そのものは CI では回らない（ADR 0004 と同じ）。CI が見るのは、`player_state.zig` のテストと、
  `--frame` / `--play-frames` / `--share-and-exit` での場面の移動と共有の文字列まで
