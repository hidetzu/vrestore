# 0002 — ROI 検出と背景復元を分ける

## 決定

ROI 検出は「動画 + 参照画像 → 固定矩形と信頼度」を返す独立したモジュールにする。
背景復元はその矩形を入力として受け取るだけで、検出の内部に依存しない。

```text
video + reference ──> ROI detection ──> ROI (x, y, w, h, confidence, reliable)
                                          │
video ─────────────────────────────────> background recovery
                                          ├─ Temporal
                                          ├─ Alpha-based
                                          └─ Spatial fallback
```

## 理由

- 復元方式は今後いくつも試す。方式を変えるたびに検出を触ると、検出精度の測定をやり直すことになる
- 検出の正しさは正解座標との比較（dx / dy / IoU）で、復元の正しさは正解画像との距離で測る。
  測り方が違うものを 1 つのモジュールにすると、どちらが悪いのか切り分けられない
- 検出結果（JSON）を人間が手で直して復元に渡す、という逃げ道が残る

## 採らなかったもの

- **検出と復元を 1 パスで行う**（例: delogo のように矩形を与えてすぐ埋める）。
  速いが、検出の誤りが「消し残り」や「関係ない所の破壊」として復元側の見た目に混ざり、測定できない
