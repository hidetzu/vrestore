# Verification

⚠ **ここは契約だけ。コマンドは書かない。** 実行するものは
[`.claude/skills/verify/SKILL.md`](../skills/verify/SKILL.md)。

## 根拠

⚠ ビルドが通ることは、それが何をするかについて何も言わない。
⚠ 自分とだけ一致する検査は何も証明していない。

## 層

| 層 | 見るもの | ⚠ 見えないもの |
|---|---|---|
| **fast** | fmt、ビルド、純粋関数のユニットテスト、リポジトリ衛生（動画が入っていないか） | 実際の動画での振る舞い |
| **合成 E2E** | CI 内で合成した動画（正解が分かっている）に対する end-to-end の数値判定 | 合成素材に無い性質（実際の圧縮・実際の透かし） |
| **実素材** | `tmp/media/` の手元の動画。人間がデバッグ画像を見る | 正解が無いので数値判定できない。CI では回らない |

- MUST: ⚠ 合成 E2E は、ROI 検出が入った時点で必須（dx / dy / IoU / reliable を機械判定）。
- MUST: ⚠ 正解との比較で判定する。自分の前回出力との比較（スナップショット）だけで良しとしない。
- MUST: ⚠ いま測っているのが**今ビルドしたもの**かを確かめる。古い成果物は前回を測る。

## 順序

1. fast を回しながら直す。⚠ 最初の失敗で止まって戻る
2. PR 前に全層。⚠ fast だけ緑は「通った」ではない
3. ⚠ 直したら最初からやり直す

## 直したとき

- MUST: 直したバグには検査を残す。
- MUST: ⚠ わざと壊して、その検査が**意図した理由で**落ちることを見る。失敗文はそのまま記録する。

## 返すもの

```
Verdict: PASS / FAIL / NOT-VERIFIED

Ran:
  <何を>  <結果>  <実行時に出た件数>      ⚠ 実行していないものは書かない
Failed:
  - <失敗文そのまま>
Not verified:
  - <回らなかった検査と理由>
Regression guard: EXISTING / ADDED-AND-PROVEN / NONE（理由）
```

- MUST NOT: ⚠ 回らなかった検査があるのに `PASS` と書かない。
