# Rules

ここは「どう書くか」。
「どう進めるか」は [`CLAUDE.md`](../../CLAUDE.md)、「何を主張してよいか」は [`docs/SPEC.md`](../../docs/SPEC.md)、
「なぜ」は [`docs/adr/`](../../docs/adr/)。

⚠ **同じことを 2 か所に書かない。** 持ち主がいる話題は「そちらを見よ」とだけ書く。

ここにあるのは**技術的な制約**で、事故が起きる前から効く。各ファイルは根拠を書く。
このリポジトリで実際に踏んだ罠は `CLAUDE.md` §7 に、それを止めるテストと一緒に置く。

| ファイル | 中身 |
|---|---|
| [`evidence.md`](evidence.md) | 観測したと言ってよいこと。分母・条件・観測と解釈 |
| [`verification.md`](verification.md) | 検証の契約。何を実行するかは `skills/verify` |
| [`git.md`](git.md) | コミット、push の許可、公開物に書かないもの |

`MUST` = 必須、`SHOULD` = 既定、`MAY` = 任意。`⚠` は「踏むと痛い」。
